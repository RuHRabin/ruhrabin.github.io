How the black hole works
The physics behind the 3D view, and where it is simplified.

        

          
Photon sphere · r = 3.2 rs

          

            
Light path

            
The shader traces each pixel's ray with a = −(3/2)·h²·r⃗ / r⁵ (rs = 1, h = |r⃗ × v⃗|), the photon-orbit form of the Schwarzschild null geodesic.

            
Photon ring

            
Light can circle at r = 1.5 rs.

            
Shadow

            
Critical impact parameter bc = 3√3/2 rs ≈ 2.598 rs.

            
Disk

            
Drawn from r = 2.6 rs to 15 rs. It is stylized: the true innermost stable orbit is r = 3 rs.

            
Your clock

            
γ(r) = 1/√(1 − 1/r), r in rs. Earth time runs γ times faster than yours. Static-observer formula. In my game I exaggerate this for gameplay; here it is the real ratio.

            
Orbits

            
Kepler's third law, T ∝ a3/2. Radius a = 8 + 20·t, with t = log₁₀(1 + days since commit) / log₁₀(271). Eccentricity, tilt and phase come from a hash of the repo name, so the layout is stable. Kepler's equation M = E − e·sin E is solved by Newton–Raphson.

            
Bodies

            
Approximate weak-field lensing for the bodies, α ≈ 2·rs / b; the background is full ray-marching. The weak-field formula breaks down below about 3 rs.

            
Camera floor

            
The camera never goes closer than r = 1.6 rs.

Questions people ask

      

        
Who is Rabin?

        
Rabin (GitHub and X handle @RuHRabin) is a lifelong learner working in machine learning and simulation. He likes taking things apart to see how they actually work, whether that is a machine learning experiment, a simulation, or a "let's see what happens" program, and then rebuilding it better. This site is his portfolio.

        
What has Rabin built?

        
Gargantua, a black-hole flight game with per-pixel gravitational lensing; Sol-Mesh, serverless encrypted messaging for Android; earthpulse, a live earthquake and severe-weather map; xkb-avro, a Bengali Avro Phonetic keyboard layout for Linux; html-bangla, an offline Android app that teaches HTML in Bengali; and Schemify, a CLI that infers typed schemas from messy CSV, TSV and JSON files. Each has its own page.

        
How accurate is the black hole?

        
The background is ray-marched: every pixel follows the Schwarzschild photon-orbit acceleration a = −(3/2)·h²·r⃗/r⁵ (rs = 1). The accretion disk is stylized (drawn from 2.6 to 15 rs, while the true innermost stable orbit is 3 rs). The clock uses the static-observer time-dilation factor γ(r) = 1/√(1 − 1/r). Small bodies use a weak-field lensing approximation that breaks down below about 3 rs.

        
Why do the projects orbit at different distances?

        
In the 3D view each public repository is a body. Size follows GitHub stars, color follows the main language, and distance follows days since Rabin's last commit: a = 8 + 20·t, with t = log₁₀(1 + days) / log₁₀(271). Orbital period follows Kepler's third law, T ∝ a3/2.

        
Do I need the 3D view?

        
No. This page is plain HTML and works with JavaScript off. The 3D view and the live instruments are optional extras that load on request.

        
How can I contact Rabin?

        
Email rabin@ruhrbin.site, or find him on X and GitHub as @RuHRabin.
